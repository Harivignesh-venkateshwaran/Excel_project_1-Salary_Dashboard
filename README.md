This data job salary dashboard was created to help job seekers investigate salaries for their desired jobs and locations.  
The data is from the Excel course i've learned, which provides a foundation in analysing data using this powerful tool. The data contains detailed information on job titles, salaries, locations and essential skills that are presented here.
